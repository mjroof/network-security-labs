Project 01: Network Fundamentals and Documentation

Overview

This project focuses on understanding, investigating, and documenting the architecture of my personal network lab.

The goal is to develop practical networking skills through hands-on experiments and technical documentation.

Objectives

- Identify devices in the lab environment.
- Document IP addresses and network interfaces.
- Understand subnet masks and CIDR notation.
- Identify default gateways and DNS servers.
- Inspect routing tables across operating systems.
- Analyze basic network traffic using Wireshark.
- Document the network topology.

Lab Environment

The lab includes macOS, Kali Linux, Windows, and virtual machines used for networking and cybersecurity experiments.

The exact configurations and network relationships will be documented during the investigation.
