# network-security-labs


About This Repository

Welcome to my hands-on networking and cybersecurity lab portfolio.

This repository documents my practical learning journey through network fundamentals, traffic analysis, network security, and cybersecurity lab environments.

My goal is to develop strong technical skills through practical experiments, systematic troubleshooting, and clear technical documentation.

Lab Environment

My lab environment includes:

- macOS
- Kali Linux
- Windows
- Virtual machines for networking and security experiments
- Wireshark for network traffic analysis

The exact network configuration and lab components will be documented as the projects progress.

Projects

01. Network Fundamentals and Documentation

- Network topology
- IP and MAC addressing
- Subnetting and CIDR
- Default gateways and routing tables
- DHCP, DNS, ARP, and ICMP

02. Network Traffic Analysis

- Packet capture and analysis with Wireshark
- ARP request and reply analysis
- ICMP traffic analysis
- DNS query analysis
- TCP connection analysis

03. Virtual Network Architecture and Security

- Virtual networking modes
- Network segmentation and isolation
- Secure lab design

Documentation Approach

Each project will include relevant objectives, methodology, evidence, technical analysis, results, and lessons learned.

All experiments will be conducted on systems and networks I own or am explicitly authorized to test.
